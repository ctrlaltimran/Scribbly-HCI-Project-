# Scribbly Usability Test Plan

## Participants

Test with at least five real users who reasonably represent the target audience or people who help them shop for stationery.

## Test tasks

1. Find the Cloud Nine Notebook and open its product page.
2. Add two notebooks to the bag.
3. Change the quantity in the bag and then remove an item. Try the Undo option.
4. Create a demo account and reach the dashboard.
5. Complete the demo checkout until the final review step, then go back and correct one detail before confirming.
6. Find the school-order form and submit a request after intentionally leaving one required field empty first.
