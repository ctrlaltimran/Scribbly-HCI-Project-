# Scribbly Brand Guide

## Logo

Use the supplied Scribbly mascot and wordmark without redrawing, changing the font, changing the mascot shape or recoloring the original artwork.

## Primary palette

Deep violet: #3F3F90
Scribbly violet: #6D71BF
Soft lavender: #C3C4E3
Soft yellow: #F5F39A
Paper cream: #FBF8EF
Ink: #1F1F24

## Supporting accents

Coral: #FF8D72
Mint: #B8EEB4
Sky: #8DDCF6
Pink: #F2B5D3

Supporting accents add child-friendly variety but should not replace the logo colors as the main visual identity.

## Typography

DM Sans: interface, headings, descriptions, buttons, navigation and forms.
Gloria Hallelujah: short handwritten accent phrases only.

## Interface rules

Use one primary action per area.
Keep button labels action-oriented and specific.
Use the same button shapes and focus treatment across screens.
Keep paragraphs short and readable.
Do not put important text on low-contrast colors.
Keep product media square and visually full.
Keep login/sign-up access visible on mobile for guest users.
Use clear feedback after actions.
Allow users to reverse or correct important actions.
